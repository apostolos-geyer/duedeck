## Architecture

- **Config source**: `packages/ui/src/tamagui.config.ts` (v5 default + CSS animations + custom container tokens)
- **Provider**: `packages/ui/src/provider.tsx` (`"use client"` wrapper for Next.js App Router)
- **Re-exports**: `packages/ui/src/index.ts` re-exports all of `tamagui` + config + provider
- **Form primitives**: `packages/ui/src/form/` — TanStack Form composition API with Tamagui-styled fields
- **Next.js plugin**: `@tamagui/next-plugin` in `apps/web/next.config.js` and `apps/docs/next.config.js`
- **Build config**: `tamagui.build.ts` in each app points to the shared config

## Tamagui Config

See `tamagui-prompt.md` (auto-generated by `bunx @tamagui/cli generate-prompt`) for the full token/theme/shorthand reference.

Re-run from `packages/ui/` to update after config changes.

### Custom Container Width Tokens

Defined as size tokens in `tamagui.config.ts`. Use with any size-mapped property (`width`, `maxW`, `minW`, `height`, etc.):

| Token | Value (px) |
|-------|-----------|
| `$container.xs` | 320 |
| `$container.sm` | 384 |
| `$container.md` | 448 |
| `$container.lg` | 512 |
| `$container.xl` | 576 |
| `$container.xxl` | 672 |
| `$container.xxxl` | 768 |
| `$container.full` | 1024 |

```tsx
<YStack width="100%" maxW="$container.sm" />
```

## Form Primitives (`@repo/ui/form`)

Import from `@repo/ui/form` (separate entry point to avoid conflicts with Tamagui's own `Form` exports).

### Hooks & HOCs

- `useAppForm` — pre-bound `useForm` with all field/form components registered
- `withForm` — HOC for breaking large forms into sub-components
- `withFieldGroup` — HOC for reusable field groups
- `formOptions` — re-exported from TanStack Form for shared config

### Field Components

Used via `form.AppField` > `field.TextField`, etc:

| Component | Type | Tamagui Component |
|-----------|------|-------------------|
| `TextField` | `string` | `Input` |
| `TextAreaField` | `string` | `TextArea` |
| `CheckboxField` | `boolean` | `Checkbox` |
| `SwitchField` | `boolean` | `Switch` |
| `RadioGroupField` | `string` | `RadioGroup` |
| `SelectField` | `string` | `Select` |

### Form Components

Used via `form.AppForm` > `form.SubmitButton`, etc:

- `SubmitButton` — auto-disables, shows spinner when submitting
- `FormErrors` — renders form-level validation errors

### Building Custom Fields

Import `useFieldContext` and `FormFieldWrapper` from `@repo/ui/form` to create your own field components that integrate with `useAppForm`.
